Removal Software

Two lightweight text-cleaning tools. Choose the version that fits what you need, download the script, and follow the setup instructions below.

TEXT FORMATTING TOOLKIT · VERSION 5.0

Text Formatting Toolkit v5.0

A text cleaner with extra formatting rules.

Controls

  • Ctrl + Alt + O — toggle cleaning ON/OFF.
  • Ctrl + Alt + P — clean the selected text while ON.

What it does

  • Removes common punctuation and hyphens.
  • Keeps exclamation marks, question marks, and parentheses.
  • Changes standalone “an” to “a”.
  • Lowercases the first character of each sentence, except standalone “I”.
Download v5.0
PUNCTUATOR REMOVER · VERSION 2.0

Punctuator Remover v2.0

A simpler tool that removes punctuation from selected text.

Controls

  • Ctrl + Alt + O — toggle remover ON/OFF.
  • Ctrl + Shift + P — clean the selected text while ON.

What it does

  • Removes periods, commas, quotes, apostrophes, colons, semicolons, and square brackets.
  • Keeps exclamation marks, question marks, parentheses, and hyphens.
  • Does not change words or sentence capitalization.
Download v2.0
Required: AutoHotkey v2.0

These downloads are .ahk scripts. You must install AutoHotkey v2.0 before opening either program.

Download AutoHotkey v2.0 from the official website

How to set it up

  1. Click the AutoHotkey v2.0 link above.
  2. Download the Windows installer from the official AutoHotkey website.
  3. Run the installer and finish installing AutoHotkey v2.0.
  4. Download either Text Formatting Toolkit v5.0 or Punctuator Remover v2.0.
  5. Open the downloaded .ahk file. The program should start.
  6. Turn it ON with Ctrl + Alt + O, select some text, and press that program's cleaning shortcut.

To close a running script, right-click its green AutoHotkey icon near the Windows clock and choose Exit. The icon may be inside the hidden-icons arrow.
